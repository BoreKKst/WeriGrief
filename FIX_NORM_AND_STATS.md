# Исправления WeriGrief

- `/norm` без аргумента теперь показывает только вызывающего команду, найденного в Google Sheets → лист `Списки`.
- Общий список сотрудников остаётся за `/check_norm`.
- Pterodactyl file API теперь запрашивает абсолютный путь `/world/stats/<uuid>.json`.
- UUID берётся из `usercache.json` (если доступен), затем используется Offline UUID как резервный вариант.
- Ошибки HTTP/API логируются с коротким фрагментом ответа, чтобы отличить неверный ключ, путь и внутреннюю ошибку панели.

Примечание: Google Sheets в текущей реализации хранит состав и накопленные часы в колонке E. Текущий онлайн за сегодня берётся из Minecraft `stats` через Pterodactyl; одной колонки накопительных часов недостаточно, чтобы вычислить онлайн за текущие сутки. Для проверки реальной доступности API нужны действующие значения из локального `.env`; они не включаются в архив.
