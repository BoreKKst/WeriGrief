# WeriGrief Staff Management Bot

Discord-бот для комплексной автоматизации управления персоналом сервера Minecraft **WeriGrief**.

---

## 🏛️ Архитектура проекта

Кодовая база очищена от временных скриптов и разделена по слоям ответственности:

```text
WeriGrief-StaffBot/
├── main.py                     # Точка входа для запуска бота
├── requirements.txt            # Зависимости Python
├── .env.template               # Шаблон конфигурации окружения
├── .gitignore                  # Исключения Git (секреты, токены, логи)
└── src/
    ├── bot.py                  # Инициализация бота, регистрация Cogs и событий
    ├── core/
    │   └── config.py           # Конфигурация, переменные окружения, логирование, реестр стаффа
    ├── services/
    │   ├── sheets_api.py       # Google Sheets API (чтение/запись варнов, списков персонала)
    │   ├── sheets_monitor.py   # Фоновая служба периодической синхронизации и сброса варнов
    │   ├── staff_resolver.py   # Разрешение ников/ID/тегов и строгая проверка прав в таблице
    │   ├── permissions.py      # Роли в Discord и синхронизация LuckPerms в Minecraft
    │   ├── playtime.py         # Подсчет онлайна через Pterodactyl API и суточная норма (/norm)
    │   └── automod.py          # Автомодерация ссылок и вайтлист доменов
    ├── cogs/
    │   ├── warnings.py         # Команды варнов: /warn, /unwarn, /warns, /clearwarns
    │   ├── staff.py            # Команды персонала: /staff, /appoint, /unstaff, /dismissed
    │   └── norm.py             # Команды онлайна: /norm, /check_norm, /norm_exempt, /help_staff
    ├── ui/
    │   └── views.py            # Интерактивные кнопки: тикеты поддержки, репорты, правила
    └── utils/
        └── embeds.py           # Генераторы форматированных Embed-сообщений
```

## ⚡ Основные возможности

1. **📊 Контроль онлайна и суточной нормы (`/norm`)**:
   - Опрос статистики серверов Paper (`world/stats/<uuid>.json`) через Pterodactyl Client API.
   - Чистый расчет разницы с 00:00 MSK с защитой от сброса статистики и защитой новичков в первый неполный день.
   - Ежесуточная автоматическая проверка в 00:00 MSK с отправкой персональных отчётов в ЛС и сводки в канал персонала.
   - Начисление отыгранных часов в колонку G листа «Списки».

2. **⚠️ Система предупреждений (`/warn`, `/unwarn`, `/warns`, `/clearwarns`)**:
   - Безопасная запись и удаление из Google Sheets (`Учет предупреждений`) с защитой от пустых строк.
   - Автоматическая выдача роли `⚠️ На испытании` при 3+ активных варнах.
   - Автоматическое снятие роли испытательного срока при снижении числа варнов ниже 3.
   - Ежемесячный автоматический сброс всех предупреждений 1-го числа каждого месяца.

3. **👥 Управление кадровым составом (`/staff`, `/appoint`, `/unstaff`, `/dismissed`)**:
   - Автоматическое назначение/снятие ролей в Discord с учетом иерархии прав бота.
   - Автоматическая синхронизация групп LuckPerms в Minecraft через консольные команды Pterodactyl API (`lp user <nick> parent set <group>`).
   - Автоматическая очистка всех активных варнов и занесение записи в архив снятого персонала при увольнении.

4. **🛡️ Безопасность и автомодерация**:
   - Строгая проверка прав: наличие роли в Discord **без** записи в таблице Google Таблицы не дает прав на управление наказаниями или персоналом.
   - Автомодерация ссылок с белым списком Tenor и Giphy и исключением тикет-каналов.

## 🚀 Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте шаблон переменных окружения:
   ```bash
   cp .env.template .env
   ```
3. Заполните `.env` (токен бота Discord, API ключ Pterodactyl, ID таблицы Google Sheets, путь к сервисному JSON ключу).
4. Запустите бота:
   ```bash
   python main.py
   ```
